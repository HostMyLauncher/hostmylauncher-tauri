# Capability discovery host

Build-only consuming Tauri application for the bridge. Its capability references
`hostmylauncher:default`; `tauri-build` must discover the bridge's permission files
through Cargo dependency metadata, without inline permission injection.

The generated application context is also compiled for MockRuntime. No window,
production API or Minecraft installation is started. It checks permission discovery
in a consuming build only, not execution inside a WebView.

From the repository root, keep outputs and temporary files on project storage:

```sh
TMPDIR="$PWD/target/test-tmp" CARGO_TARGET_DIR="$PWD/target" \
  cargo check --manifest-path examples/capability-host/Cargo.toml
```

Without the bridge dependency, the build fails to resolve `hostmylauncher:default`:
the permissions must come from the plugin's build metadata, not a manually inserted ACL.

`gen/` is generated by Tauri and ignored. This host is a development fixture and is
not published.
