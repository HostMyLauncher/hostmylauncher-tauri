# Capability discovery host

Build-only consuming Tauri application for the bridge. Its capability references
`hostmylauncher:default`; `tauri-build` must discover the bridge's permission files
through Cargo dependency metadata, without inline permission injection.

The generated application context is also compiled for MockRuntime. No window,
production API or Minecraft installation is started. This closes consuming-host
build/discovery proof only, not real WebView execution.

From the repository root, keep outputs and temporary files on project storage:

```sh
TMPDIR="$PWD/target/test-tmp" CARGO_TARGET_DIR="$PWD/target" \
  cargo check --manifest-path examples/capability-host/Cargo.toml --offline
```

The initial RED omits the bridge dependency and must fail to resolve
`hostmylauncher:default`. The GREEN includes the real plugin dependency; permissions
must come from its build metadata, not a manually inserted ACL.

`gen/` is generated by Tauri and ignored. Both this host and its local bridge/base
dependencies remain non-publishable development fixtures.
